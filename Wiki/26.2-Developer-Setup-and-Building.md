## 2. Environment Configuration

1. **Install OpenJDK 25**:
   Download and install Eclipse Adoptium Temurin OpenJDK 25.
2. **Set JAVA_HOME**:
   ```bash
   # Windows PowerShell
   $env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-25.0.3.9-hotspot"
   
   # Linux / macOS
   export JAVA_HOME=/usr/lib/jvm/jdk-25
   ```
3. **Verify Installation**:
   ```bash
   java -version
   ```

---

## 3. Step-by-Step Compilation Guide

To build the dedicated `1.0.1+26.2` binary:

```bash
# Navigate to subproject directory
cd "Combat Cooldown Adjuster v26.2/combat-cooldown-adjuster"

# Run non-daemon build
./gradlew build --no-daemon
```

### Output Binaries:
Upon successful compilation, artifacts will be generated in `build/libs/`:
* `combat-cooldown-adjuster-1.0.1+26.2.jar`
* `combat-cooldown-adjuster-1.0.1+26.2-sources.jar`

## 4. Loom & Properties Breakdown

