## 2. Step-by-Step Player Survival Workflow

1. **Charging Your Strike**:
   Allow your attack meter to fill beyond $80\%$ charge scale ($S > 0.8$). Because weapon delays are calibrated to fast intervals (e.g. 4 ticks for Swords), this threshold is reached in just $3.2\text{ ticks}$ ($0.16\text{ seconds}$).
2. **Striking the Target**:
   Left-click an entity. The attack executes, triggering `Player#attack(Entity target)`.
3. **Multi-Layer Visual Hit Sparks**:
   The server instantly emits a burst of 10 sharp `CRIT` particles accompanied by 5 magic `ENCHANTED_HIT` particles centered at the entity's bounding box height ($y + 0.5h$).
4. **Dynamic Combo Pitch Escalation**:
   The game plays `SoundEvents.PLAYER_ATTACK_STRONG`. Attacks landed near maximum charge scale trigger a pitch-shifted audio cue up to $1.4\times$ higher than normal, delivering tactile, arcade-style feedback for well-timed hits.
5. **Configurable Toggle**:
   If you prefer silent or particle-free combat, simply toggle the GameRule off:
   ```mcfunction
   /gamerule ig:enable_combat_juice false
   ```

## 3. Mathematical Formulas & Audio Equations

### Trigger Threshold Condition
Combat Juice triggers if and only if:
$$\text{JuiceEnabled} = \text{true} \quad \land \quad S_{\text{strength}} > 0.8$$
where $S_{\text{strength}} = \text{player.getAttackStrengthScale}(0.5f) \in [0.0, 1.0]$.

### Dynamic Audio Pitch Shift Formula
The audio playback pitch for `SoundEvents.PLAYER_ATTACK_STRONG` is dynamically calculated as:
$$\text{Pitch} = 1.0 + (S_{\text{strength}} - 0.8) \times 2.0$$

#### Boundary Analysis:
* At lower bound threshold ($S_{\text{strength}} = 0.8$):
  $$\text{Pitch} = 1.0 + (0.8 - 0.8) \times 2.0 = 1.00$$
* At midpoint charge ($S_{\text{strength}} = 0.9$):
  $$\text{Pitch} = 1.0 + (0.9 - 0.8) \times 2.0 = 1.20$$
* At absolute maximum charge ($S_{\text{strength}} = 1.0$):
  $$\text{Pitch} = 1.0 + (1.0 - 0.8) \times 2.0 = 1.40$$

Thus:
$$1.0 \le \text{Pitch} \le 1.4$$

### Particle Emission Counts & Spatial Offsets
When triggered, particles are emitted on the `ServerLevel` at target coordinates $(x, y_{0.5}, z)$:
* **`ParticleTypes.CRIT`**: Count $N = 10$, spatial delta $(\Delta x = 0.1, \Delta y = 0.1, \Delta z = 0.1)$, particle speed $0.1$.
* **`ParticleTypes.ENCHANTED_HIT`**: Count $N = 5$, spatial delta $(\Delta x = 0.1, \Delta y = 0.1, \Delta z = 0.1)$, particle speed $0.1$.

## 7. Developer & Mixin Hooks

### Hook in `PlayerMixin.java`:
```java
@Inject(method = "attack", at = @At("HEAD"))
private void cca$applyJuice(Entity target, CallbackInfo ci) {
    Player player = (Player) (Object) this;
    CCAHooks.applyCombatJuice(player, target);
}
```

### Static Engine Implementation in `CCAHooks.java`:
```java
public static void applyCombatJuice(Player player, Entity target) {
    if (!CombatRules.getBoolean(player.level(), CombatRules.ENABLE_JUICE)) return;

    float attackStrength = player.getAttackStrengthScale(0.5f);
    if (attackStrength > 0.8f) {
        if (player.level() instanceof ServerLevel serverLevel) {
            serverLevel.sendParticles(ParticleTypes.CRIT, target.getX(), target.getY(0.5), target.getZ(), 10, 0.1, 0.1, 0.1, 0.1);
            serverLevel.sendParticles(ParticleTypes.ENCHANTED_HIT, target.getX(), target.getY(0.5), target.getZ(), 5, 0.1, 0.1, 0.1, 0.1);
        }
        
        // Pitch shifting logic: Higher pitch for high-charge hits
        float pitch = 1.0f + (attackStrength - 0.8f) * 2.0f; // Range: 1.0 to 1.4 approx
        player.level().playSound(null, target.getX(), target.getY(), target.getZ(), 
            SoundEvents.PLAYER_ATTACK_STRONG, SoundSource.PLAYERS, 1.0f, pitch);
    }
}
```
