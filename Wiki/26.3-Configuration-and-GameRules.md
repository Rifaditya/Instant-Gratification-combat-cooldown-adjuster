## 2. Step-by-Step Player & Administrator Workflow

1. **Viewing Current Rules**:
   Open chat and type `/gamerule ig:`. The tab-completion engine displays all 9 registered rules along with their current values.
2. **Modifying Attack Delays**:
   To set the sword cooldown delay to 2 ticks:
   ```mcfunction
   /gamerule ig:sword_cooldown_ticks 2
   ```
3. **Enabling Pure 1.8 Click-Spam Combat**:
   To eliminate attack cooldown entirely for swords:
   ```mcfunction
   /gamerule ig:sword_cooldown_ticks 0
   ```
4. **Toggling Swap Agility**:
   To enable or disable hotbar swap persistence:
   ```mcfunction
   /gamerule ig:prevent_item_swap_cooldown true
   ```
5. **Managing Combat Juice**:
   To toggle visual particle bursts and pitch-shifted audio:
   ```mcfunction
   /gamerule ig:enable_combat_juice true
   ```

## 3. Mathematical Bounds & Player Agency Invariant

### The Anti-Nanny Invariant
Combat Cooldown Adjuster strictly adheres to the **Player Agency & Anti-Nanny Invariant**:
* **No Arbitrary Max Caps**: Players and server administrators are free to set tick delays as high as desired (up to `Integer.MAX_VALUE` = $2,147,483,647$). If a server administrator wants a weapon to take 100 ticks ($5\text{ seconds}$) to recharge, the engine fully supports it.
* **Non-Negative Lower Bound Guard**: The only enforced lower boundary is $T \ge 0$. Negative values ($T < 0$) are guarded to prevent arithmetic division-by-zero or sign inversion errors in vanilla attack calculations.

## 7. Developer & Mixin Hooks

### Accessing Rules in Java Code:
```java
// Query integer tick value with client-safety fallback
int swordTicks = CombatRules.getInt(level, CombatRules.SWORD_TICKS);

// Query boolean toggle with client-safety fallback
boolean swapAgility = CombatRules.getBoolean(level, CombatRules.PREVENT_SWAP_RESET);
```

### Dynamic Registration in `CombatRules.java`:
```java
public static void register() {
    SWORD_TICKS = DynamicGameRuleManager.registerInteger("ig:sword_cooldown_ticks", COMBAT_COOLDOWN, 4);
    AXE_TICKS = DynamicGameRuleManager.registerInteger("ig:axe_cooldown_ticks", COMBAT_COOLDOWN, 8);
    PICKAXE_TICKS = DynamicGameRuleManager.registerInteger("ig:pickaxe_cooldown_ticks", COMBAT_COOLDOWN, 4);
```
