Этот мод устраняет искусственную задержку перед атакой, введённую в обновлении 1.9+, восстанавливая динамичный и отзывчивый боевой процесс с настраиваемыми тиками задержки и сочной аудиовизуальной отдачей.

## ⚡ Ключевые возможности

1. **Категориальная задержка атак в тиках**:
   Настройка кулдауна атак по тегам предметов (`#minecraft:swords`, `#minecraft:axes`, `#c:spears` и т.д.). Меч по умолчанию восстанавливается за 4 тика (5 ударов/сек), топор за 8 тиков, мотыга за 1 тик (20 ударов/сек). Установка значения в `0` активирует мгновенный спам-клик в стиле Minecraft 1.8!
2. **Ловкость хотбара (Swap Agility)**:
   Игровое правило `ig:prevent_item_swap_cooldown` предотвращает сброс шкалы атаки при переключении слотов хотбара, обеспечивая непрерывные комбо.
3. **Боевой сок (Combat Juice)**:
   При ударе с зарядом шкалы более 80% ($S > 0.8$) генерируются вспышки критических и зачарованных частиц, а звук удара динамически повышает тон от $1.0\times$ до $1.4\times$.
4. **Динамические GameRules через DasikLibrary**:
   Все 9 параметров настраиваются прямо на сервере командой `/gamerule` без перезагрузки мира.

## 📊 Сводная таблица GameRules

| Игровое правило | Тип | По умолчанию | Описание |
| :--- | :---: | :---: | :--- |
| `ig:sword_cooldown_ticks` | Целое | `4` | Задержка атаки для мечей в тиках (0.2 сек) |
| `ig:axe_cooldown_ticks` | Целое | `8` | Задержка атаки для топоров (0.4 сек) |
| `ig:pickaxe_cooldown_ticks` | Целое | `4` | Задержка атаки для кирок |
| `ig:shovel_cooldown_ticks` | Целое | `2` | Задержка атаки для лопат |
| `ig:hoe_cooldown_ticks` | Целое | `1` | Задержка атаки для мотыг (сверхбыстрые удары) |
| `ig:spear_cooldown_ticks` | Целое | `6` | Задержка атаки для копий (`#c:spears`) |
| `ig:generic_cooldown_ticks` | Целое | `4` | Задержка для прочих предметов и кулаков |
| `ig:prevent_item_swap_cooldown` | Логическое | `true` | Не сбрасывать шкалу атаки при смене предмета |
| `ig:enable_combat_juice` | Логическое | `true` | Включить частицы и динамический звук при ударе |
